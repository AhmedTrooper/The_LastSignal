# Viking 1 source image

`hirise-lander.jpg` is an unmodified local copy of the lander enlargement linked from the official HiRISE caption for **PSP_001521_2025**.

- Original: https://static.uahirise.org/images/2007/details/cut/PSP_001521_2025_cut_b.jpg
- Source and caption: https://www.uahirise.org/PSP_001521_2025
- Credit: **NASA/JPL-Caltech/UArizona**
- Observation acquired **22 November 2006**; caption published **4 December 2006**.
- Downloaded through BrowserOS neo, using a same-origin blob download because the original JPEG displays inline rather than triggering a download. Copied without cropping or transcoding.
- Size: **350,773 bytes**.
- SHA-256: `6ef16244d06c5c2f530cadba5bddccf3f789d6534dad850d51a29b1cdf990a61`.

The original remote JPEG loaded in the browser, but the local development image optimizer returned HTTP 500 for HiRISE remote images. This local copy remains optimizable without that upstream dependency. The much larger site overview remains a source link, not an eagerly embedded mobile image.

Identifying the lander does not establish the present condition of its electronics. The accompanying source describes nearby entry-hardware identifications as candidates/likely locations.
