Downloaded with BrowserOS neo and verified **2026-11-08**. No frames, soundtrack, timings or overlays were added or removed.

This is a **data-driven animation**, not a spacecraft camera movie or live signal. It illustrates LRO LAMP's ultraviolet viewport encountering the impact vapor cloud. The depicted signal is the difference between post-impact observations and observations from LRO's previous orbit, used to enhance the plume above background. The 30-second movie's playback is not the entire mission's real-time observing duration.
